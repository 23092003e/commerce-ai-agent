## Rulings

- Work in the existing checkout on a dedicated feature branch. Existing dependency installation and Docker support made this practical; `main` remains unchanged.
- Restore the broken dependency archive without upgrading versions or changing the lockfile. Cost if incorrect: a clean reinstall must reproduce the same package contents; container clean installation is the independent check.
- Use a standalone production Compose file, rather than merging development ports into production. Cost: operators must use the explicit `-f docker-compose.production.yml` command documented in the runbook.
- Keep demo operations local while implementation is changing. No external traffic, real Page test or deployment is inferred from local green tests.
- A model may choose only allowlisted connective phrases; product, policy and transactional facts come from server-validated tool evidence. This reduces hallucinated claims but limits conversational variety and still needs a real-provider evaluation.
