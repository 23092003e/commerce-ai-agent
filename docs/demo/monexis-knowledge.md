# Monexis: demo information

This content is fictional and intended only for the portfolio demonstration.

Monexis là cửa hàng bánh và đồ ngọt giả lập phục vụ trình diễn. Sản phẩm, giá và tồn kho là dữ liệu mẫu. Đơn hàng tạo trong bản demo không được giao hàng hay thanh toán thật.

The deployed demonstration has one indexed document using the configured OpenRouter embedding model at 1,536 dimensions. Indexing this file again is not required for ordinary startup. On November 9, 2026, one Messenger test asking whether demo orders are delivered reached `knowledge.search`, returned this document as evidence, and sent the correct no-delivery/no-payment response. This is one observed scenario, not a reliability guarantee; recheck the current deployment and model before a presentation.

On the same date, a separate unrelated air-conditioner warranty question reached `knowledge.search`, returned zero evidence and sent a human-handover notice. This verifies one no-evidence path; it does not prove retrieval or model quality for arbitrary questions.
